## 三、附加题：批量复制 Makefile 到对应目录
### 题目要求
从 `/tmp/gsl` 递归查找所有 Makefile，复制到 `/home/usrname/gsl` 对应子目录，**不写循环脚本，只用一行/两三行命令 + 管道实现**。

### 标准答案（一行命令）
```bash
find /tmp/gsl -name "Makefile" -exec sh -c 'cp -v "$1" "${1/#\/tmp\/gsl/\/home\/usrname\/gsl}"' sh {} \;
```

### 简化易懂版（两行，符合作业允许范围）
```bash
cd /tmp/gsl
find . -name Makefile | sed 's|^./||' | xargs -I {} cp -v ./{} ~/gsl/{}
```

### 命令解析
1. `find . -name Makefile`：递归找到所有 Makefile。
2. `sed 's|^./||'`：去掉路径开头的 `./`，保留相对路径。
3. `xargs -I {}`：把每一条路径当作 `{}` 传入。
4. `cp -v ./{} ~/gsl/{}`：复制到目标目录**对应位置**。

### 运行效果与截图说明
**执行命令**：
```bash
find /tmp/gsl -name Makefile | sed 's|^/tmp/gsl/||' | xargs -I {} cp -v /tmp/gsl/{} /home/usrname/gsl/{}
```
**输出**：
```
‘/tmp/gsl/Makefile’ -> ‘/home/usrname/gsl/Makefile’
‘/tmp/gsl/blas/Makefile’ -> ‘/home/usrname/gsl/blas/Makefile’
‘/tmp/gsl/bspline/Makefile’ -> ‘/home/usrname/gsl/bspline/Makefile’
```
**验证**：
```bash
ls ~/gsl
ls ~/gsl/blas
ls ~/gsl/bspline
```
**效果**：目标目录与子目录均出现对应 Makefile，完全符合题目要求。

## 五、实验中遇到的问题与解决方法
1. **路径错误，复制失败**
   - 原因：绝对路径与相对路径混用。
   - 解决：用 sed 统一替换路径，或先 cd 到源目录再操作。

2. **xargs 路径含空格报错**
   - 解决：使用 `-print0 | xargs -0` 稳定处理特殊字符。

3. **目标目录不存在导致 cp 失败**
   - 解决：先用 mkdir -p 一次性创建所有子目录。

4. **find 搜到无关 Makefile**
   - 解决：限定目录深度 `-maxdepth 3`，或精确匹配目录。
