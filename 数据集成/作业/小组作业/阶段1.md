# 阶段1 · 数据库表部分（Hive → Spark ETL → ClickHouse）

`default` 库 10 张 `*info` 表

**10 张表**：`dm_v_as_djk_info`，`dm_v_as_djkfq_info`，`pri_credit_info`，`pri_star_info`，`pri_cust_asset_acct_info`，`pri_cust_asset_info`，`pri_cust_base_info`，`pri_cust_liab_acct_info`，`pri_cust_liab_info`，`pri_cust_contact_info`（该表仅走小作业，不与其余表混分析）。

## 一、ETL

### 1. 读入（9 张通用表 + 小作业表共用）

1. `JdbcDialect` 注册后，`jdbc` 读 Hive；`dbtable` 为表名，或 `(SELECT * FROM t LIMIT n) tmp`（调试）。
2. 列名：对 `a.b` 只保留 `**b`**（去掉表名或 `tmp` 前缀）。

### 2. 九张通用表（含 `pri_cust_liab_acct_info`）

对 DataFrame **依次**做：

```
out = dropDuplicates()
out = filter( 行内「至少存在一列」非空 )
```

- `**dropDuplicates()**`：Spark 语义为 **所有列联合完全相同** 才算重复，**只删整行拷贝**，不会删「仅部分字段相同」的行。  
- `**filter`**（`rowHasSomeValue`）：**当且仅当** 每一列都是 `NULL`，或 **String** 类型 `**trim` 后为空**，则丢行；**任一列**非 NULL，且非字符串或字符串 trim 后非空，则 **保留**。非字符串列（数值、日期等）只要非 NULL 即视为有值 **保留**。

可选：`HW3_GENERIC_AGG=true` 时再按 **第一列** `groupBy` + 其余列 `first(ignoreNulls)`

### 3. 小作业表 `pri_cust_contact_info`

1. 取列 `uid`、`con_type`、`contact`（忽略大小写）。
2. 丢掉：`uid` 空，或 `contact` 为 NULL / 空 / `"无"` / `"-"`。
3. `RDD`：`groupByKey(uid)` → `mapValues`：TEL/OTH/MOB 归 `**contact_phone`**，其余类型归 `**contact_address**`，多值英文逗号拼接，`**LinkedHashSet` 去重顺序**。
4. 写入 `**pri_cust_contact_info_etl`**（三列）。

### 4. 写出

`jdbc` → ClickHouse，`**Overwrite**`；九张同名；小作业结果表名见上。

## 二、ClickHouse 容器内启动（无 `sudo`）

`service clickhouse-server start` 会调用 `sudo -u clickhouse`，容器里常未装 `sudo` 会失败。可改用：

```bash
mkdir -p /var/run/clickhouse-server /var/lib/clickhouse
chown -R clickhouse:clickhouse /var/run/clickhouse-server /var/lib/clickhouse /var/log/clickhouse-server 2>/dev/null || true

su -s /bin/bash clickhouse -c '/usr/bin/clickhouse-server --config-file /etc/clickhouse-server/config.xml --daemon'
```

验证：`clickhouse-client --host 127.0.0.1 -q "SELECT 1"`
