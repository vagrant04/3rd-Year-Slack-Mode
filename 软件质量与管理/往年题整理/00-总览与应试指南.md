# 软件质量与管理 往年题整理总览

## 考试基本信息

- **考试形式**：闭卷笔试
- **教师**：荣国平
- **历年考题来源**：2013、2014、2015A/B、2016、2018、2020(mid)、2021、2023

## 题型分布（以2023年为例）

| 题型 | 分值 | 说明 |
|------|------|------|
| 不定项选择题 | 30分（15题×2分） | 多选、少选均可能扣分 |
| 判断题 | 6分 | 判断正误并说明理由 |
| 简答题 | 9-10分/题 | 约4-5题 |
| 论述题 | 10分/题 | 需要较详细展开 |

## 核心考点分布

| 模块 | 高频考点 | 出现频次 |
|------|--------|--------|
| 软件过程与方法论 | 三大阶段、生命周期模型、瀑布模型 | 极高 |
| 敏捷方法 | 敏捷宣言、Scrum特征、XP vs 规范方法 | 极高 |
| 过程改进 | CMMI五级、PDCA/IDEAL | 高 |
| 项目估算 | PROBE方法、规模估算要点 | 高 |
| 质量指标 | A/FR、PQI、DRL、Yield | 高 |
| 项目管理 | EVM挣值管理、WBS、项目计划 | 高 |
| 团队管理 | 自主团队、TSP角色、知识工作领导者 | 中高 |
| DevOps | 三步法、特点、最佳实践 | 中 |
| 需求开发 | 客户需求vs产品需求、V&V | 中 |
