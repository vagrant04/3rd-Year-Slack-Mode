## ⚠️ 注意事项

1. **不能直接调用Ragas API**
   - 任务要求"不允许直接调用Ragas等第三方库的顶层评估API"
   - 需要阅读源码后自己复现算法逻辑
   - 可以参考Ragas的实现思路,但代码要自己写

2. **代码规范**
   - 所有代码添加详细中文注释
   - 变量命名清晰易懂
   - 函数添加docstring说明

3. **Git提交规范**
   - 每次提交都要注明个人姓名
   - commit message清晰描述改动内容
   - 频繁提交,方便追踪个人贡献

4. **AI辅助标注**
   - 在AI生成的代码中添加注释: `# AI辅助生成,由[姓名]调整优化`
   - 不要盲目复制AI生成的代码,要理解原理

5. **文档质量**
   - 图文并茂,使用架构图和流程图
   - 参考学长文档,但不要抄袭
   - 突出自己的思考和创新点
