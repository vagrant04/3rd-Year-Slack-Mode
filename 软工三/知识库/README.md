# 软工三知识库

本目录用于集中管理软工三课程的所有学习资料和参考文档。

## 📁 目录结构

### 📋 课程要求/
存放官方课程文档和任务说明
- `2026软工三-课程说明-0302.pdf` - 课程总体介绍
- `2026软工三-团队创建与软件过程要求.pdf` - 团队组建和开发流程规范
- `2026软工三-迭代一任务说明.pdf` - 迭代一具体任务要求

### 📚 参考资料/
存放学长资料和参考文档
- `2026软工三-开源项目分析文档示例.pdf` - 官方提供的文档示例
- `学长-Ragas项目分析文档.pdf` - 往年学长的优秀作业
- `参考-大语言模型辅助的软件开发实践指南-202502.pdf` - AI辅助开发指南
- `参考-开源软件泛读、标注和维护报告文档.pdf` - 开源项目分析方法论

### 📖 技术文档/
存放技术框架和工具的文档
- Ragas官方文档
- LLM Agent开发框架文档
- Python相关技术文档

### 💻 开发资源/
存放源码和代码示例
- Ragas项目源码 (克隆后存放于此)
- 示例代码
- 实验脚本模板

### 📝 团队文档/
存放团队内部文档
- 会议记录
- 技术决策记录
- 开发日志
- 个人贡献报告

## 🔍 使用说明

### 查找课程要求
需要了解某个迭代的具体任务时,查看 `课程要求/` 目录下对应的PDF文件。

### 学习参考案例
在开始写文档前,先阅读 `参考资料/` 中的学长案例和官方示例,学习优秀文档的结构和写作风格。

### 技术学习
需要学习Ragas或Agent开发时,查看 `技术文档/` 和 `开发资源/` 目录。

### 团队协作
所有团队会议记录和开发日志统一存放在 `团队文档/` 目录,方便追溯和查阅。

## ⚠️ 注意事项

1. **不要直接修改原始文档**: 课程要求和参考资料都是只读的,如需做笔记请另外创建文件
2. **定期更新**: 每次迭代开始时,将新的任务说明文档放入对应目录
3. **版本控制**: 所有文档都应该提交到Git,方便团队同步
4. **命名规范**: 新增文档请使用清晰的命名,包含日期和内容描述
