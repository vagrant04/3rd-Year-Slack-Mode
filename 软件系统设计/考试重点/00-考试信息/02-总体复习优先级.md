## 1. 总体复习优先级

### 1.1 最高优先级：必须会背、会画、会套场景

1. 质量属性场景六要素：Source, Stimulus, Environment, Artifact, Response, Response Measure。
2. ASR 的定义、来源、识别方法：需求文档、QAW/访谈、业务目标、Utility Tree。
3. 4+1 视图：Logical, Process, Physical, Development + Use Case。
4. 三类架构视图/风格：Module、C&C、Allocation，以及各自典型例子。
5. ADD 过程 8 步。
6. ATAM 过程、输出、Risk/Sensitivity Point/Trade-off Point。
7. 架构模式迁移：单体 -> 主机/终端 -> C/S -> 三层/分层 -> SOA -> 微服务，并补充事件驱动/云原生。
8. 微服务架构：适用原因、服务拆分、质量属性取舍、关键模式。
9. 七大面向对象设计原则：SRP、OCP、LSP、DIP、ISP、CRP、LoD。
10. 策略、工厂方法、抽象工厂、命令、观察者、组合、状态、适配器、装饰者、外观、代理等模式的意图、结构、适用场景和取舍。
11. 模式分类与组合：创建型 + 结构型 + 行为型联合使用，能解释为什么这样组合。
12. 详细设计部分所有课程课件都属于考试范围，重点只是复习优先级，不是唯一范围。

### 1.2 高频设计题模板

1. 质量属性场景建模题：给业务需求，写六要素并说明质量属性。
2. 架构设计题：给业务系统，识别 ASR，选架构模式，说明质量属性取舍，画 C&C/部署/4+1 图。
3. 微服务设计题：给平台类系统，拆服务、选通信方式、说明数据库和容错策略。
4. 设计模式应用题：用 Strategy/Observer/Composite/Command 等画类图并解释原则，注意多个模式联合使用。
5. 设计分析题：给已有设计，指出违背原则、耦合问题、扩展性问题、性能/可用性隐患，并给改进方案。
6. 微服务综合题：服务拆分、核心模式、六边形架构图、容器化部署、部署运维组合考。
