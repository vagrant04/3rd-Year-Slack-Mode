本目录按年份收录原题、仓库中已有的非官方答案，以及重新校核后生成的参考答案。

## 答案与可信度说明

1. 仓库中未发现教师发布的官方参考答案。
2. “现有答案”来自学长学姐笔记、`Exam0-往年考试.pdf`、`往年考题综合.docx` 或既有的“往年题整理”，均为非官方答案；本目录尽量保留其原意并附原文件链接。
3. “AI 校核答案”依据课程 PPT、旧课件和复习资料重新作答。对于概念口径存在差异的题目，会给出判分点和合理口径，而不是声称只有一种表述。
4. 回忆版缺失的题干不会被补造；只能由其他年份同题确认的内容会标记为“重建题意”。
5. Mermaid 类图用于表达 UML 关系；考试手绘时应补齐可见性、参数、返回值、多重性和箭头方向。
