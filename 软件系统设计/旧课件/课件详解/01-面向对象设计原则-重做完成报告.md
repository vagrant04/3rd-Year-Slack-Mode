## 🔧 新版本的改进方法

### 步骤1: 文本密度分析 ⭐ 核心创新
```bash
# 逐页提取文本并统计字符数
for i in {1..59}; do
  text=$(pdftotext -f $i -l $i "课件.pdf" -)
  chars=$(echo "$text" | wc -m)
  echo "$i,$chars"
done
```

**判断标准**:
- 字符数 < 30: 几乎肯定是图为主 → 必须提取图像
- 字符数 30-150: 可能有重要图表 → 建议提取图像
- 字符数 > 600: 以文字为主 → 文本分析即可

**结果**: 识别出**21个**需要图像分析的页面

### 步骤2: 批量提取图像
```bash
# 提取21个关键页面
pages=(1 3 4 8 16 17 19 21 22 27 32 35 39 40 45 47 51 54 55 56 59)
for page in "${pages[@]}"; do
  pdftoppm -png -f $page -l $page "课件.pdf" "/tmp/oop-page-$page"
done
```
