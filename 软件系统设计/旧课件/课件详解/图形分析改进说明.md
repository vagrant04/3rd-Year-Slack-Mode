## 改进的工作流程

### 新增步骤：图像分析

#### 1. 提取关键页面图像
```bash
# 批量提取所有"实例解析"页面
for page in 15 20 27 37 43 50 57 59; do
  /opt/homebrew/bin/pdftoppm -png -f $page -l $page "课件.pdf" "/tmp/page-$page"
done
```

#### 2. 读取并分析图像
```python
Read tool: /tmp/page-XX-XX.png
```

分析要点：
- UML类图的完整结构
- 类的属性和方法
- 类之间的关系类型（继承↑、实现△、关联→、依赖--→）
- 重构前后的对比

#### 3. 补充到文档
在章节详解中添加：
```markdown
### UML类图分析
[基于图像的准确描述]

### 类关系详解
[说明关联、继承等关系的含义]
```

## 技术方案

### 方案1: pdftoppm + Read工具 ⭐ 推荐
```bash
# 转换PDF页面为PNG图像
pdftoppm -png -f [页码] -l [页码] input.pdf output-prefix

# 使用Claude的视觉能力分析
Read tool: output-prefix-[页码].png
```

**优点**:
- Claude可以直接"看到"UML图
- 能准确理解类图结构
- 能识别关系类型

### 方案2: 文本 + 人工校验
```bash
# 提取文本
pdftotext input.pdf

# 人工查看PDF，补充图形信息
```

**缺点**: 效率低，容易遗漏

### 方案3: OCR识别
```bash
# 使用tesseract OCR
tesseract image.png output
```

**缺点**: 对图形的识别不如Claude的视觉能力
